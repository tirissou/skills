# Personal

Skills written for my own workflow, on top of the upstream set. Not part of the
plugin, and not promoted: upstream never touches this bucket, which is what
keeps merges from `mattpocock/skills` clean. See [../../fork/STRATEGY.md](../../fork/STRATEGY.md).

- **[align-language](./align-language/SKILL.md)**: Settle a load-bearing term that is new and overloaded, or that we are using differently, before the design is built on it.
- **[evaluate-output](./evaluate-output/SKILL.md)**: Re-run the commands that prove a chunk of work, then turn the result into one self-contained HTML eval page.
- **[visual-design-review](./visual-design-review/SKILL.md)**: Draw each option of a design fork as modules and seams, compare them, and recommend one, on a single HTML page.
